# 额度与计费

账户余额以**美元额度**显示，调用时按模型价格和分组倍率扣除。模型价格、分组倍率和充值优惠以[控制台](https://api.mugua.link)为准。

## 充值比例

本站充值比例为 **0.5 元人民币 = 1 美元额度**。在控制台“钱包管理”中充值，也可以使用兑换码。

很多站点按 1 元 = 1 美元额度充值，因此本站显示的倍率数字看起来可能更高。比较价格时请换算成人民币，以实际消费为准。

## 扣费方式

| 计费方式 | 适用 | 计算 |
| --- | --- | --- |
| 按量计费 | 大多数文本模型 | 按输入、输出 token 和模型价格计算，再乘以分组倍率 |
| 按次计费 | `gpt-image-2` 等图片模型及部分特殊渠道 | 每次（每张）固定价格，再乘以分组倍率 |

**分组倍率**由令牌所属分组决定：倍率越低越便宜，`Free` 分组倍率为 0。同一模型在不同分组中价格不同，选择方法见[分组与令牌](/guide/groups)。

“模型广场”（需登录）列出每个模型在各分组下的价格与计费方式。缓存、推理 token、多模态输入的统计方式可能因模型而异。

开启 `stream: true` 只改变传输方式，本身不额外收费。

## 核对一次消耗

1. 确认请求使用的模型 ID 和令牌。
2. 在接口响应中查看 `usage`。
3. 在控制台“使用日志”中找到对应记录，查看实际分组、token 数和扣费。

| 协议 | 常见字段 |
| --- | --- |
| Chat Completions | `usage.prompt_tokens`、`usage.completion_tokens` |
| Responses | `usage.input_tokens`、`usage.output_tokens` |
| Anthropic Messages | `usage.input_tokens`、`usage.output_tokens` |

输出 token 可能包括模型内部推理等不可见内容，返回文本的长度不一定等于计费的输出量。流式请求中途断开时客户端可能收不到完整统计；最终以使用日志为准。

## 免费额度

- **签到**：控制台支持每日签到领取额度。
- **邀请奖励**：邀请好友注册，邀请人与被邀请人都可获得额度，具体数量见控制台。
- **Free 分组**：免费模型不保证可用性，只用于正常体验，禁止刷量和高频翻译类调用。

## 控制成本

- 为不同项目和工具使用独立令牌，并为令牌设置额度上限。
- 根据任务选择模型和分组，控制输入历史长度和输出上限。
- 使用 `auto` 分组的跨分组重试时，留意请求可能切换到倍率更高的分组。
- 使用有次数限制的重试，避免 SDK、网关和业务层叠加重试；按次计费的模型尤其要注意。
- 发生网络超时时，先检查使用日志；服务端可能已经执行请求并扣费。

## 额度问题与限流

| 现象 | 处理 |
| --- | --- |
| 用户额度不足 | 账户余额用完，需要充值 |
| 令牌额度已用尽 | 令牌设置的额度上限用完，在令牌管理中调整 |
| `429` | 频率或并发限制，降低并发，按 `Retry-After` 或退避策略重试 |

需要退款或对扣费有疑问，可以联系管理员。详细说明见[错误处理](/reference/errors)。
