# 分组与令牌

木瓜 API 中，**令牌**就是调用接口使用的 API Key。每个令牌都属于一个**分组**，分组决定这个令牌能调用哪些模型、走哪类渠道，以及按什么倍率计费。

同一个模型 ID 在不同分组中可能价格、稳定性和效果都不同。请求失败或效果不符合预期时，先确认令牌所在的分组。

## 创建令牌

1. 登录[控制台](https://api.mugua.link)，进入“令牌管理”，点击“添加令牌”。
2. 填写名称，选择**分组**。
3. 按需设置额度上限、过期时间、模型限制和 IP 白名单；个人使用可以保持默认。
4. 保存后复制以 `sk-` 开头的令牌，填入 SDK 或工具。

令牌的分组可以在之后编辑修改，修改后对新请求生效，无需更换工具里的 Key。

## 分组怎么选

| 分组类型 | 说明 | 适合 |
| --- | --- | --- |
| `auto` 自动分组 | 按模型自动选择可用分组，站点推荐 | 不想手动挑选、追求可用性 |
| 优质 Claude / Codex / Grok | 官方高级账号号池，稳定和效果优先 | 编程助手、对质量敏感的任务 |
| 特价 Claude / Codex / Gemini / Grok / 国产 | 价格优先，稳定性或效果可能略低 | 预算敏感、可以接受偶发不可用 |
| 特殊 Claude 等其他分组 | 特定渠道，详见控制台说明 | 按分组描述选择 |
| `default` 默认分组 | 基础分组 | 按控制台说明使用 |
| Free 免费分组 | 倍率为 0，不保证可用性 | 体验和测试 |

分组名称、说明和倍率会随渠道调整，以控制台“添加令牌”中的分组列表和模型广场为准。

### 按工具选择

| 工具 | 建议分组 |
| --- | --- |
| Claude Code | Claude 类分组（优质 / 特价 / 特殊 Claude），或 `auto` |
| Codex | Codex 类分组（优质 / 特价 Codex），或 `auto` |
| OpenCode、OpenClaw、Cherry Studio | 与所选模型对应的分组，或 `auto` |
| 图片生成 | 支持 `gpt-image-2` 的分组，见[图片生成](/reference/images) |

模型所属的分组可以在“模型广场”中查看（需登录）。为不同工具分别创建令牌，便于按用途切换分组和查看消耗。

## 自动分组与跨分组重试

`auto` 分组会为请求的模型选择当前可用的分组。创建令牌时选择 `auto` 并开启**跨分组重试**，某个分组暂时不可用时可以自动切换到其他分组，减少中断。

自动切换后，请求可能落到倍率更高的分组。在“使用日志”中可以看到每次请求实际使用的分组和扣费。

## 常见提示

| 提示 | 原因与处理 |
| --- | --- |
| 当前分组下对于模型无可用渠道 | 该分组不提供这个模型，或渠道暂时不可用；换用支持该模型的分组，或改用 `auto` |
| 模型不存在 / 模型不可用 | 检查模型 ID 拼写，并确认它在令牌所属分组中 |
| 令牌额度已用尽 | 提高令牌额度上限或设为不限 |
| 用户额度不足 | 账户余额不足，需要充值 |
| 令牌已过期 / 已禁用 | 在令牌管理中调整过期时间或重新启用 |

更多状态码见[错误处理](/reference/errors)。

## 使用规范

- 所有分组禁止越狱、破限等违规用法，违规账号会被封禁；误封可以联系管理员申诉。
- 免费模型供正常体验使用，不支持沉浸式翻译等高频调用的工具，异常刷量会被封禁。
- 平台规则以控制台公告为准。
