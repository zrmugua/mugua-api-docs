# 分组与令牌

木瓜 API 中，**令牌**就是调用接口使用的 API Key。每个令牌都属于一个**分组**，分组决定这个令牌能调用哪些模型、走哪类渠道，以及按什么倍率计费。

具体分组名称、号池说明和倍率会随渠道动态调整，均以[控制台](https://api.mugua.link)“添加令牌”页面和“模型广场”的实时展示为准。

## 创建令牌

1. 登录[控制台](https://api.mugua.link)，进入“令牌管理”，点击“添加令牌”。
2. 填写名称；分组默认已选为 `auto`，也可按需切换为控制台列出的其他分组。
3. 按需设置额度上限、过期时间、模型限制和 IP 白名单；个人使用可以保持默认。
4. 保存后复制以 `sk-` 开头的令牌，填入 SDK 或工具。

令牌的分组可以在之后编辑修改，修改后对新请求生效，无需更换工具里的 Key。建议为不同工具分别创建令牌，便于按用途切换分组和查看消耗。

## 查看当前分组与可用模型

- **查看分组说明与倍率**：在控制台“添加令牌”的分组下拉框中查看当前所有分组及描述。
- **查看模型所属分组**：登录后在“模型广场”搜索目标模型，确认哪些分组支持它以及具体计费方式。

同一个模型 ID 在不同分组中的价格、稳定性和效果可能不同。请求失败或效果不符合预期时，先确认令牌所属分组以及控制台中的最新说明。

## 自动分组与跨分组重试

不确定选哪个分组时，直接使用默认的 `auto` 分组即可，它会为请求的模型自动选择当前可用的分组。

创建或编辑令牌时开启**跨分组重试**，某个分组暂时不可用时可以自动切换到其他可用分组，减少业务中断。自动切换后请求可能落到倍率更高的分组，实际命中的分组与扣费可在“使用日志”中核对。

## 常见提示

| 提示 | 原因与处理 |
| --- | --- |
| 当前分组下对于模型无可用渠道 | 该分组不提供这个模型，或渠道暂时不可用；换用支持该模型的分组，或改用 `auto` |
| 模型不存在 / 模型不可用 | 检查模型 ID 拼写，并确认它在令牌所属分组中 |
| 令牌额度已用尽 | 在“令牌管理”中提高令牌额度上限或设为不限 |
| 用户额度不足 | 账户余额不足，需要充值 |
| 令牌已过期 / 已禁用 | 在“令牌管理”中调整过期时间或重新启用 |

更多状态码见[错误处理](/reference/errors)。

## 使用规范

- 所有分组禁止越狱、破限等违规用法，违规账号会被封禁；误封可以联系管理员申诉。
- 免费体验模型仅用于正常测试，不支持沉浸式翻译等高频调用工具，异常刷量会被封禁。
- 平台规则、上新与调整通知会在控制台公告和[木瓜 API 用户群](https://qm.qq.com/q/Q90cLKHh2k)中发布。
