# 常见问题

## Base URL 应该填哪个

OpenAI SDK、Codex 和 OpenAI 兼容工具一般使用 `https://api.mugua.link/v1`。Claude Code 和 Anthropic SDK 使用 `https://api.mugua.link`，由工具追加 `/v1/messages`。

客户端提供“完整端点”字段时，需要填写完整路径。详见[接入地址](/guide/base-url)。

## 模型 ID 从哪里获取

登录后在“模型广场”复制，或使用[模型列表接口](/reference/models)。完整 ID 包括可能存在的大小写、版本和渠道后缀。新模型上线和旧模型下线会在控制台公告及[木瓜 API 用户群](https://qm.qq.com/q/Q90cLKHh2k)中通知。

模型出现在列表中，表示当前 Key 可见该模型。协议、上下文长度、图片、工具调用等能力需另外确认。

## 分组是什么，应该选哪个

每个令牌属于一个分组，分组决定可用模型、渠道和倍率。由于分组说明与倍率随渠道动态调整，具体以控制台“添加令牌”和“模型广场”的实时展示为准。不确定怎么选时，保持默认的 `auto` 分组并开启跨分组重试即可。详见[分组与令牌](/guide/groups)。

## 为什么本站倍率看着比别的中转站高

本站充值比例为 0.5 元 = 1 美元额度，多数站点为 1 元 = 1 美元额度，所以倍率数字不能直接对比。换算成人民币后，以实际消费为准。可以用[额度与计费](/guide/billing#充值比例)页里的换算工具直接核对。

## 提示“当前分组下无可用渠道”怎么办

令牌所在分组不提供这个模型，或该分组渠道暂时不可用。在模型广场确认模型所属分组，在“令牌管理”中修改令牌分组，或改用 `auto`。

## 已有 OpenAI SDK 能直接使用吗

可以为 SDK 设置木瓜 API 的 `baseURL` / `base_url` 和自己的 API Key。具体方法和协议仍需模型支持。运行示例见[SDK 配置](/guide/sdk)。

## Key 可以保存在桌面客户端里吗

个人 Key 可以保存在自己的受信任设备和客户端中，并保护配置、备份和导出文件。面向他人分发的浏览器代码、小程序或 App 应通过自己的后端请求 API，避免嵌入共享密钥。见[鉴权与安全](/guide/auth)。

## 设置了环境变量为什么还提示缺少 Key

变量只对当前进程及其子进程生效。从开始菜单启动的编辑器、已运行的客户端和后台服务，可能不会继承终端临时设置的变量。

在正确的启动环境中设置，或使用工具支持的持久凭据管理，然后重启相关程序。

## 为什么返回 401、403、404 或 503

- `401`：检查 Key、鉴权头和实际凭据来源。
- `403`：检查错误体中的拒绝原因，常见为账户余额不足、令牌额度用尽或模型限制。
- `404`：检查最终 URL 的路径拼接、模型 ID 和协议。
- `503`：常见为令牌分组下没有该模型的可用渠道，或上游渠道暂时不可用。

按[故障排查](/guide/troubleshooting)逐项定位。

## 429 都是余额不足吗

不是。本站余额不足通常返回 `403` 并提示用户额度不足；`429` 多为频率或并发限制，也可能是上游渠道限流。先读取错误体：限流需要降低并发并有限退避，额度问题则需要在控制台处理。见[错误处理](/reference/errors#平台常见错误)。

## 开启流式输出会额外收费吗

`stream` 控制响应传输方式。具体价格取决于模型与平台规则，实际消耗以用量和控制台记录为准。流中断后也可能已经产生用量，见[额度与计费](/guide/billing)。

## 工具能打开，是否说明配置成功

工具启动、本机健康检查、模型列表和真实生成分别验证不同环节。发送消息并在木瓜控制台核对调用记录，可以确认这次上游模型调用。

编程助手的工具调用还需通过实际任务验证。

## 同时用多个开发工具怎么配置

可以选择 [CC Switch](/cli/cc-switch) 管理各工具配置，或使用 [AIO Coding Hub](/cli/aio-coding-hub) 本机网关。单工具配置直接从[工具接入](/guide/tools)选择对应页面。

## 连接不稳定或很慢

可以切换线路试试：主站 `https://api.mugua.link` 和 CF 站 `https://api.668851.xyz` 使用同一套令牌，只需替换域名。见[线路选择](/guide/base-url#线路选择)。

## 有免费额度吗

控制台支持每日签到和邀请奖励；控制台标注的免费体验模型可用于正常测试，但不保证可用性，禁止刷量和沉浸式翻译等高频调用。

## 哪些用法会被封号

所有分组禁止越狱、破限等违规操作；免费模型异常刷量也会被封禁。认为被误封可以联系管理员申诉。

## 可以退款吗

需要退款请联系管理员。

## 仍然无法定位怎么办

按[故障排查](/guide/troubleshooting#联系管理员时提供)整理报错时间、工具版本、模型、路径和脱敏错误信息，再加入[木瓜 API 用户群](https://qm.qq.com/q/Q90cLKHh2k)联系管理员。模型上新、抽奖活动与站点通知也会统一在群内发布。
